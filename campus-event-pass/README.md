# Campus Event Pass Generator

## 1. Project Title
Campus Event Pass Generator

## 2. Objective
To develop a user-friendly web application that allows students to register for campus events and generate a digital event pass.

## 3. Problem Statement
Managing event registrations manually can be time-consuming and inconvenient. This project provides a simple digital solution where users can enter their details, select an event, validate their information, and generate an event pass.

## 4. Tech Stack
- React
- JavaScript
- HTML
- CSS
- Vite

## 5. Implementation Approach
The application is developed using React components. A registration form collects the user's details and validates the entered information. React state is used to manage the form data. After successful validation, a digital event pass containing the registration details is displayed.

## 6. Features
- User registration form
- Name and email input
- Event selection
- Form validation
- Digital event pass generation
- Responsive user interface
- React component-based implementation

## 8. How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   npm install

5. Start the development server:

   npm run dev

6. Open the local URL shown in the terminal.
