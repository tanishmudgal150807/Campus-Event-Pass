# Web Development Tasks

This repository contains three web development projects completed as part of the assigned tasks.

## Projects

### Task 1 — Campus Event Pass Generator

A React-based event registration application that allows users to enter their details, select an event, and generate a digital event pass.

[View Task 1](./Task-1-Event-Pass)

### Task 2 — Notes App

A React-based Notes application supporting CRUD operations, search/filtering, reusable components, and LocalStorage persistence.

[View Task 2](./Task-2-Notes-App)

### Task 3 — Blog/CMS Mini App

A full-stack blog management application built with React, Node.js, and Express.js, featuring REST API-based CRUD operations and JSON data storage.

[View Task 3](./Task-3-Blog-CMS)
